## 📂 Projects

### 📡 2D Ultrasonic Environmental Scanner

A real-time 2D environmental scanning prototype built using an Arduino Uno, HC-SR04 ultrasonic sensor, and SG90 servo motor.

The sensor sweeps across its surroundings and collects distance measurements at different angles, which are visualized on a computer.

This project helped me work with:

- Arduino hardware
- Ultrasonic sensors
- Servo motors
- Serial communication
- Hardware and software integration

---

### ☀️ Solar Tracker

An electronics project that uses LDR sensors and servo motors to track the direction of a light source.

I've worked on the circuit, sensor readings, servo control, prototyping, and troubleshooting the hardware.

This project helped me understand:

- LDR sensors
- Voltage dividers
- Servo motor control
- Arduino programming
- Breadboard prototyping
- Hardware debugging
